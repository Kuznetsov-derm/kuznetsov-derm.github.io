# Сайт Кузнецова Андрея Сергеевича (дерматовенеролог, Казань)

Статический сайт без бэкенда. Публикуется на GitHub Pages.

## Файлы

| Что | Где |
|---|---|
| Страница | `index.html` |
| Фотографии кейсов «до/после» | `img/cases/case-*.jpg` |
| Список кейсов | `cases.json` |
| Главное фото и портрет | `img/hero.jpg`, `img/portrait.jpg` |
| Шрифты | `fonts/` |

## Добавить случай «до/после» (без программирования)

1. Подготовить кадр: одно изображение «до/после» (два кадра рядом), до 1200 px по
   длинной стороне. Сжать на macOS одной командой (в Терминале, из папки с фото):
   `sips -Z 1200 -s format jpeg -s formatOptions 72 фото.jpg --out case-9.jpg`
2. Открыть репозиторий на github.com → зайти в папку `img/cases`.
3. **Add file → Upload files** → перетащить `case-9.jpg` → **Commit changes**.
4. Вернуться в корень репозитория → открыть `cases.json` → карандаш (Edit).
5. Дописать строку по образцу предыдущей — **не забыв запятую** после предыдущей строки:

```json
  { "src": "img/cases/case-8.jpg", "alt": "Клинический случай 8: слева кожа до лечения, справа — после" },
  { "src": "img/cases/case-9.jpg", "alt": "Клинический случай 9: слева кожа до лечения, справа — после" }
```

6. **Commit changes** → через ~1 минуту сайт обновится сам.
7. Проверить: открыть сайт в режиме инкогнито (иначе поможет кэш).

Пропорции кадра указывать не нужно — страница измерит файл сама.

## Локальный просмотр

Двойной клик по `index.html` не подходит: браузер не даёт странице читать `cases.json`
с диска (кейсы не покажутся). Локально смотреть так:

```bash
cd /path/to/папка && python3 -m http.server 8000
```

и открыть http://localhost:8000
